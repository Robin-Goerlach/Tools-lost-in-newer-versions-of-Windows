# NT-Clipboard

**Status: conceptual scaffold — utility features not implemented.**

A possible compact viewer for the current clipboard contents, inspired by classic Windows clipboard tools.

This directory contains a minimal Windows Forms project that opens a concept placeholder window. No utility features are implemented. This is a just-for-fun hobby idea with no deadline or commitment to implementation.

[Back to the repository overview](../README.md) · [Deutsche Übersicht](../README.de.md)

## Build

Open [NT-Clipboard.sln](NT-Clipboard.sln) in Visual Studio 2022 with the .NET desktop development workload and .NET 8 SDK installed, then build and run. Alternatively, use `dotnet build NT-Clipboard.sln` on Windows.

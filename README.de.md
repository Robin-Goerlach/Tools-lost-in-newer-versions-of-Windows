# Tools lost in newer versions of Windows

Kleine, eigenständige Windows-Werkzeuge, inspiriert von vertrauten Programmen aus der klassischen Windows-Zeit.

[English](README.md) | **Deutsch**

## Warum es dieses Projekt gibt

Manche ältere Windows-Werkzeuge bleiben wegen ihres Erscheinungsbilds, ihrer Einfachheit und ihrer Bedienung in guter Erinnerung. Dieses Repository erkundet, wie sich dieses Gefühl mit kleinen, eigenständigen Anwendungen zurückbringen lässt.

Dies ist ein **Hobbyprojekt – just for fun und nice to have**: Raum zum Experimentieren, für etwas Nostalgie und für nützliche Programme, wenn Zeit und Lust vorhanden sind. Es gibt keine Fristen, zugesagten Veröffentlichungstermine oder Verpflichtungen, jede Idee umzusetzen.

## Projektphilosophie

- **Wiedererkennbares klassisches Windows-Erscheinungsbild.** Vertraute Gestaltung und einfache Arbeitsabläufe erhalten, wo sie die Orientierung erleichtern.
- **Sinnvolle Modernisierung.** Bedienbarkeit, Zuverlässigkeit und Kompatibilität verbessern, wenn es praktisch sinnvoll ist.
- **Kein verbissener pixelgenauer Nachbau.** Das Original dient als Inspiration, nicht als Vorgabe, für die wir uns mit umständlichem Code oder unnötigem Aufwand verbiegen.
- **Kleine, eigenständige Werkzeuge.** Jede Anwendung hat ihren eigenen Zweck und darf sich in ihrem eigenen Tempo entwickeln. Umsetzung und Dokumentation bleiben dem Hobbyprojekt angemessen.

## Vorhandene Anwendungen

| Anwendung | Beschreibung |
| --- | --- |
| [NT-Clock](NT-Clock/README.md) | Eine von Windows NT 4.0 inspirierte Windows-Forms-Uhr mit analoger und digitaler Anzeige, Alarm und Infobereich-Unterstützung. |
| [NT-FileManager](NT-FileManager/README.md) | Ein retro-inspirierter Windows-Forms-Dateimanager mit klassischen Verzeichnisfenstern, Baumansicht und alltäglichen Dateioperationen. |

Diese Verzeichnisse enthalten Implementierungen. Details und Hinweise zum Bauen stehen in den jeweiligen READMEs. Die Anwendungsdokumentation ist derzeit teilweise englisch und teilweise deutsch; für diese Repository-Übersicht ist Englisch die Standardsprache, ergänzt durch diese verlinkte deutsche Übersetzung.

## Ideen zum Erkunden

Die folgenden Verzeichnisse sind **konzeptionelle Platzhalter, keine implementierten Anwendungen**. Sie halten Möglichkeiten fest, keinen verbindlichen Entwicklungsplan oder eine Lieferzusage.

| Idee | Mögliche Richtung |
| --- | --- |
| [NT-Write](NT-Write/README.md) | Ein kleines Schreibprogramm, inspiriert vom klassischen Windows Write. |
| [NT-Cardfile](NT-Cardfile/README.md) | Eine einfache Karteiverwaltung, inspiriert von Windows Cardfile. |
| [NT-ProgramManager](NT-ProgramManager/README.md) | Ein Programmstarter mit vertrauten Programmgruppen. |

## Bauen und Erkunden

Beginne mit der README und der Projektmappe einer vorhandenen Anwendung. Die aktuellen Anwendungen verwenden C# und Windows Forms; als Entwicklungsumgebung ist Visual Studio 2022 unter Windows dokumentiert. Jede Anwendung wird separat gebaut.
